# Licensing

Proof of One uses different licences for different kinds of work. Each future source file will carry an SPDX identifier in its header.

| Part | Licence | Why |
|---|---|---|
| Phone app, relay service, enclave service and other applications | [AGPL-3.0-only](LICENSES/AGPL-3.0-only.txt) | Anyone who runs a modified version as a service must publish their changes, so the network stays open and auditable |
| Reusable libraries, zero-knowledge circuits and smart contracts | [Apache-2.0](LICENSES/Apache-2.0.txt) | Permissive, so other projects can reuse and audit the building blocks; includes a patent grant |
| Documentation, whitepaper, specifications, figures and logo | [CC-BY-SA-4.0](LICENSES/CC-BY-SA-4.0.txt) | Free to share and adapt with attribution, under the same licence |

The file [LICENSE](LICENSE) at the root contains the AGPL-3.0 text as the default for code that does not state otherwise.

Licence choices will be reviewed by a qualified lawyer before the first code release.
