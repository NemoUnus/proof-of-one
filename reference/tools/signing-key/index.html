Make the app's signing key

Proof of One pilot app. Android installs a new version over an old one only if both are signed with the same key. This page makes that key, in this browser only.

Nothing leaves this page. The key is made by your browser and the page is not allowed to connect to any server. You copy two values into the repository's secrets yourself. Never send them to anyone, including the project's AI agents.
1. Secret name: POO_KEYSTORE_B64
2. Secret name: POO_KEYSTORE_PASSWORD
3. Keep a copy offline (optional but recommended): download the key file and keep it, with the password above, somewhere safe and private. If the key is lost, every member would have to reinstall the app once more.
